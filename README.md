## 🚀 **Getting Started**

### **Prerequisites**
- Node.js 18+ 
- npm or yarn
- Expo CLI
- iOS Simulator (Mac) or Android Emulator
- Expo Go app on physical device

### **Installation**

1. **Clone the repository**
   ```bash
   git clone https://github.com/canerekinci/denenmem.git
   cd denenmem
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```
   
   **Or start on specific port (8083)**
   ```bash
   npm run start
   ```

4. **Run on devices**
   ```bash
   # iOS Simulator
   npm run ios
   
   # Android Emulator
   npm run android
   
   # Web Browser
   npm run web
   ```

### **Development Server**
The app runs on **port 8083** by default for QR code access via Expo Go app.
